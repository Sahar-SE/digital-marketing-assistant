- (decision) Paradigm: Layered + Hexagonal hybrid — UI layer, Application Services layer, Domain Core (Brand DNA, Prompt Library, Ethical Firewall), Infrastructure layer (LLM adapters, platform APIs, storage). Domain core has zero outward dependencies
- (decision) Brand DNA is the universal context prefix — every LLM call must be prefixed with the user's Brand DNA JSON. No generation may occur without a resolved Brand DNA profile. Prevents generic AI output and hallucination
- (decision) Ethical Firewall is a mandatory publish gate — content may not be exported or published unless all checks pass OR each flagged item is human-verified. Gate is always visible, never silent. Prevents unverified/biased/hallucinated content from leaving the platform
- (decision) Refinement-not-regeneration rule — the Human-AI Handshake sends delta instructions to refine existing content, never discards and restarts. Prevents API cost explosion and preserves user edit history
- (decision) Prompt templates are first-class data entities — stored as structured objects {id, category, subcategory, template_body, variables[], performance_score, platform, industry}. No prompt logic embedded in application code. Prevents prompt drift and enables the self-growing library
- (decision) Canvas text is always a separate layer — AI image generation produces visual/background layers only. Text is rendered as independent canvas elements (never baked into raster). Prevents uneditable AI-generated text artifacts
- (decision) Tiered LLM model strategy — draft generation uses fast/cheap model (gemini-flash or gpt-4o-mini), final polish and complex analysis uses capable model (gemini-pro or gpt-4o). Image generation uses dedicated image API. Prevents runaway API costs
- (decision) Platform integrations are adapter-pattern — all external platform APIs (Meta, TikTok, Google, LinkedIn) wrapped as interchangeable adapters behind a PlatformPort interface. Prevents tight coupling to any single platform's API changes
- (decision) Three-phase access model — Phase 1 Marketing Assistant (free trial, credit-limited), Phase 2 Content + Prompt Library (paid subscription), Phase 3 Product Design Canvas (subscription unlock). Feature flags control access per tier
- (assumption) [ASSUMPTION] Stack: Next.js 14 (App Router) frontend, Node.js/Express backend API, PostgreSQL for relational data, Redis for caching and queues, Supabase for auth — web-first, mobile-responsive. Needs user confirmation
